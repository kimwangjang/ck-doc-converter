# 문서 일괄 변환기

한글, 워드, 엑셀, 파워포인트 문서를 폴더째 PDF로 바꾸는 Windows 프로그램입니다.
청강문화산업대학교 교육혁신센터에서 교내 업무용으로 만들었습니다.

## 내려받기

[최신 설치 파일 받기](https://github.com/kimwangjang/ck-doc-converter/releases/latest)

Assets에서 `ck-doc-converter-setup-v….exe`를 받아 실행합니다.

## 필요한 프로그램

| 변환할 문서 | 필요한 프로그램 |
|---|---|
| 한글 (`.hwp`, `.hwpx`, 배포용 포함) | 한/글 |
| 워드 (`.doc`, `.docx`) | Microsoft Word |
| 엑셀 (선택) | Microsoft Excel |
| 파워포인트 (선택) | Microsoft PowerPoint |

Windows 64비트용입니다. 설치에는 관리자 권한이 필요합니다.

## 설치

1. 설치 파일을 실행합니다.
2. `Windows의 PC 보호` 창이 뜨면 [추가 정보] → [실행]을 누릅니다. 전자서명이 없는 교내 제작 프로그램이라 표시되는 창입니다.
3. 관리자 승인 창에서 [예]를 누르고 안내대로 진행합니다.
4. 한/글을 닫고, 마지막 화면의 변환 테스트를 켠 채 [마침]을 누릅니다.

바탕 화면 바로가기와 PDF 프린터는 자동으로 준비됩니다.

## 사용

1. [폴더 찾기]로 폴더를 선택합니다. 하위 폴더까지 포함됩니다.
2. 변환할 파일 형식을 켭니다. 엑셀과 파워포인트는 기본으로 꺼져 있습니다.
3. 변환 방식과 PDF 저장 위치를 정합니다.
4. [변환 시작]을 누르고 파일 목록에서 상태를 확인합니다.

## 꼭 지켜 주세요

- 변환 전에 한/글 문서를 저장하고 한/글을 닫아 주세요. 변환 중 한/글이 자동으로 종료되어, 저장하지 않은 문서가 사라질 수 있습니다.
- 파워포인트를 변환할 때는 PowerPoint도 닫아 주세요.
- 변환 중에는 기본 프린터가 잠시 바뀌므로 다른 문서를 인쇄하지 마세요.
- 빠른 변환은 넓은 표의 오른쪽이 잘릴 수 있고, 잘린 표도 정상처럼 보입니다. 평가 증빙, 대외 제출 문서는 정확 변환을 쓰세요.

자세한 내용은 설치 후 시작 메뉴의 `문서 일괄 변환기 사용 안내`를 참고하세요.

## 제거

Windows 설정 → 앱 → 설치된 앱 → `문서 일괄 변환기` → 제거
